# microscope_40x_color_doublets

Generated by `notebooks/tests.ipynb` (section *40x colour microscope with Thorlabs achromatic doublets*) on 2026-11-25.

## Description

Same 40x infinity-corrected colour microscope as the singlet version (LA1116-A + LA1172-A, N-BK7 plano-convex, saved in `results/microscopes/microscopio_40x_color_lentes_gruesas.png`), with both singlets replaced by Thorlabs cemented achromatic doublets of the same focal length. Each doublet is modelled as a thick element (three refracting surfaces, two glasses) and traced separately for the C (656.3 nm), d (587.6 nm) and F (486.1 nm) lines, with the refractive index of each glass from its Sellmeier equation.

The objective is mounted reversed (flint SF5 towards the object, crown N-BAK4 towards the collimated space) and the tube lens in its normal orientation (crown N-BK7 towards the collimated beam), following the Thorlabs recommendation of facing the collimated beam with the crown side. The object sits at the front focal distance of the objective, the lenses are separated by BFD_obj + FFD_tube, and the sensor is at the back focal distance of the tube lens, all for the d line.

The test checks, per colour channel, that the width of a reference feature (the 3 vertical bars of group −2, element 1, 27.35 µm in the object) measured on the sensor equals |M| times its object width, with M the A element of that colour's system matrix (tolerance 2 % + 2 sensor px + one object pixel projected on the sensor). It also reports the longitudinal chromatic focal shift: the distance from the sensor to the in-focus image plane of each colour, compared with the singlet microscope (matrices only).

Δfocus is the distance from the sensor to the plane where that colour is in focus (paraxial, sensor placed for the d line). It is large in absolute terms because the longitudinal magnification is M² ≈ 1600: a focal shift of a few µm in the objective becomes millimetres at the sensor.

## Files

Sensor images are saved at native sensor resolution (1 image px = 1 sensor px), 8-bit, no interpolation. Each colour channel is normalised to the 99.5th percentile of its non-zero pixels (`rays_to_image`), so brightness is not comparable between channels. The image is inverted (M < 0).
