# two_lenses_focus

Generated by `notebooks/tests.ipynb` (section *Two lenses*) on 2026-10-26.

## Description

Two thin lenses (f1 = 50 mm, f2 = 50 mm) image a USAF 1951 target placed 100 mm in front of lens 1. Lens 1 forms an intermediate image at s1' = 100.0 mm. The separation d between the lenses is varied, which changes the object distance for lens 2, s2 = d − s1' (negative means a virtual object), and therefore the final image distance d_i = s2' and the total magnification M = M1·M2. For each d the sensor is placed at d_i behind lens 2 and at d_i·(1 ± 0.05) to produce defocused images. The test checks:

1. **Magnification**: the system matrix element A matches the sequential thin-lens magnification M = M1·M2.
2. **Image size**: the width of a reference feature (the 3 bars of group −2, element 1) on the sensor matches |M| times its width in the object (683.8 µm), tolerance 2 % + 2 sensor px. Edges are taken at 50 % of the maximum of the column profile averaged over the ROI rows. A local feature is used because at the largest magnifications the full target is larger than the sensor (on purpose, to show the magnification), so its outline is clipped.
3. **Focus**: the sharpness inside the ROI is highest at d_i. Sharpness is the variance of the Laplacian, computed on the full image and then cropped to the ROI.

Each image is normalised to the 99.5th percentile of its non-zero pixels (`rays_to_image`), so brightness is not comparable between files. A positive M means an upright final image, a negative M an inverted one.
