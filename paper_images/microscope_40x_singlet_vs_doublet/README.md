# microscope_40x_singlet_vs_doublet

Generated by `notebooks/tests.ipynb` (section *40x colour microscope with Thorlabs achromatic doublets*, comparison cell) on 2026-11-25.

## Description

Side-by-side comparison of the same 40x infinity-corrected colour microscope built with N-BK7 plano-convex singlets (Thorlabs LA1116-A objective + LA1172-A tube lens) and with cemented achromatic doublets of the same focal lengths (Thorlabs AC050-010-A + AC254-400-A, see `../microscope_40x_color_doublets/README.md`). Both image the same RGB USAF 1951 target with the sensor at the back focus of the tube lens for the d line (587.6 nm), so red (656.3 nm) and blue (486.1 nm) are defocused by the chromatic focal shift of each system.

Both systems use the same NA (the singlet aperture is scaled so that its ray cone equals the doublet one), so the differences come from the lenses only.

Metrics, per colour, on the column profile averaged over the reference bars (group −2, element 1):

- **Δfocus**: paraxial distance from the sensor to the in-focus plane of that colour.
- **Edge vs G**: position of the left edge of the first bar (50 % level) relative to the green one, on the sensor.
- **10–90 %**: width of the first rising edge between 10 % and 90 % of the plateau level (median of the profile above 50 % of its maximum), on the sensor: the edge blur. "≥" marks a lower bound: the blur extends beyond the reference window, so the 10 % level is already exceeded at its border.

The variance of the Laplacian used as sharpness in the focus tests is not reported: with random ray sampling the pixel noise dominates it, and it rates the blurred channels as sharper.
