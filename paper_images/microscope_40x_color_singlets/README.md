# microscope_40x_color_singlets

Generated by `notebooks/tests.ipynb` (section *40x colour microscope with real Thorlabs thick lenses*) on 2026-11-25.

## Description

40x infinity-corrected colour microscope built from two Thorlabs N-BK7 plano-convex singlets: LA1116-A (f = 10 mm) as objective and LA1172-A (f = 400 mm) as tube lens. Each lens is modelled as a thick lens (two refracting surfaces) and traced separately for the C (656.3 nm), d (587.6 nm) and F (486.1 nm) lines, with the refractive index of N-BK7 from its Sellmeier equation. The objective has its flat side towards the object and its curved side towards the collimated space; the tube lens has its curved side towards the collimated beam. The object sits at the front focal distance of the objective, the lenses are separated by BFD_obj + FFD_tube, and the sensor is at the back focal distance of the tube lens, all for the d line.

The test checks, per colour channel, that the width of a reference feature (the 3 vertical bars of group −2, element 1, 27.35 µm in the object) measured on the sensor equals |M| times its object width, with M the A element of that colour's system matrix (tolerance 2 % + 2 sensor px + one object pixel projected on the sensor). It also reports the longitudinal chromatic focal shift: the distance from the sensor to the in-focus image plane of each colour. The achromatic-doublet version of this microscope is in `../microscope_40x_color_doublets/` and the side-by-side comparison (at equal NA) in `../microscope_40x_singlet_vs_doublet/`.

Δfocus is the distance from the sensor to the plane where that colour is in focus (paraxial, sensor placed for the d line). It is large in absolute terms because the longitudinal magnification is M² ≈ 1600: a focal shift of tens of µm on the object side becomes tens to hundreds of millimetres at the sensor. The measured magnification of the defocused channels is affected by the blur of the bar edges.

## Files

Sensor images are saved at native sensor resolution (1 image px = 1 sensor px), 8-bit, no interpolation. Each colour channel is normalised to the 99.5th percentile of its non-zero pixels (`rays_to_image`), so brightness is not comparable between channels. The image is inverted (M < 0).
