# microscope_magnification

Generated by `notebooks/tests.ipynb` (section *Magnification*) on 2026-10-27.

## Description

Infinity-corrected microscopes built from two thin lenses (objective f_obj and tube lens f_tube = 200 mm, separated by f_obj + f_tube, sensor at the back focal plane of the tube lens) image a USAF 1951 target placed at the front focal plane of the objective. The nominal magnifications are 5x, 10x, 20x, 40x, 60x (f_obj = f_tube / M). The target is large enough that it overflows the sensor from 10x up, so the field of view shrinks visibly as M grows. The test checks:

1. **Magnification**: the system matrix element A equals −M (inverted image).
2. **Image size**: the width of a reference feature (the 3 vertical bars of group 1, element 1, next to the centre of the target, 68.42 µm in the object) measured on the sensor equals |M| times its object width, tolerance 2 % + 2 sensor px + one object pixel projected on the sensor (|M|·p_obj): each object pixel is imaged as a single point, so at high magnification an edge can only be located to within one object pixel (29.5 µm on the sensor at 60x). Edges are taken at 50 % of the maximum of the column profile averaged over the reference rows. The dimension lines in the figure show the measured width divided by |M|, which should reproduce the object width.

The sensor images are interpolated after the ray tracing (`_interpolate_sparse_channel`, linear interpolation between ray hits). The fill radius is set to the spacing between neighbouring object pixels on the sensor, |M|·p_obj / pixel size, so that high magnifications do not show a grid of isolated dots.
