# thin_lens_focus

Generated by `notebooks/tests.ipynb` (section *Focus*) on 2026-10-26.

## Description

A single thin lens (f = 50 mm) images a USAF 1951 target placed at several object distances d_o. For each d_o the sensor is placed at the image distance from the thin-lens equation, d_i = 1 / (1/f − 1/d_o), and at d_i·(1 ± 0.05) to produce defocused images. The test checks:

1. **Magnification**: the system matrix element A matches the thin-lens magnification M = −d_i / d_o.
2. **Image size**: the width of a reference feature (the 3 bars of group −2, element 1) on the sensor matches |M| times its width in the object (683.8 µm), tolerance 2 % + 2 sensor px. Edges are taken at 50 % of the maximum of the column profile averaged over the ROI rows. A local feature is used because at the largest magnifications the full target is larger than the sensor (on purpose, to show the magnification), so its outline is clipped.
3. **Focus**: the sharpness inside the ROI is highest at d_i. Sharpness is the variance of the Laplacian, computed on the full image and then cropped to the ROI.
