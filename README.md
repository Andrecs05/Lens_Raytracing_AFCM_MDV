# Lens Ray Tracing AFCM MDV

Python tools for paraxial optical ray tracing, chromatic aberration simulation, and telescope and microscope system modeling. The codebase focuses on matrix optics, refractive index dispersion, and image remapping through simple optical systems.

## What is in this repo

- `src/`: core optical models and image and ray utilities
- `scripts/`: small entry-point scripts, currently a placeholder `main.py`
- `notebooks/`: interactive checks and experiments, currently `class_tests.ipynb`
- `assets/`: sample source images used for simulations
- `results/`: generated output images from example runs
- `README.md`, `pyproject.toml`, `__init__.py`: project metadata and package entry points

The `original_project/` folder is legacy material and is intentionally excluded from this README.

## Core modules

### `src/matrix_formation.py`

Defines the ABCD matrix building blocks used throughout the project:

- translation matrices for free-space propagation
- refraction matrices at spherical surfaces
- thin lens, thick lens, doublet, and triplet transfer matrices
- reflection matrices for mirrors

### `src/elements.py`

Wraps the low-level matrices in small optical element classes:

- `ThickLens`
- `ThinLens`
- `Mirror`
- `Doublet`
- `Triplet`
- `FreeSpace`
- `Eye`

### `src/refractive_idxs.py`

Provides Sellmeier-based refractive index models, including:

- `NBK7`
- `NBAF10`
- `NSF6HT`
- `NSF2`
- `BaF2`
- `CaF2`
- additional helper models for other materials

### `src/utilities.py`

Contains the image and ray conversion utilities plus color-aware system updates:

- `image_to_rays_0_angle`
- `image_infinity_to_rays`
- `rays_to_image`
- `rays_to_image_infinity`
- `pad_to_shape`
- `update_elements_color`

### `src/systems.py`

Defines higher-level optical systems built from the elements and matrices:

- `OpticalSystem`
- `GalileanTelescope`
- `KeplerianTelescope`
- `BrightFieldMicroscope`

`OpticalSystem` supports monochrome and RGB paths, focal length and magnification inspection, and image propagation through a system matrix.

## Usage

### Run the placeholder script

```bash
python scripts/main.py
```

### Work with the optical systems in Python

```python
import cv2
from src.refractive_idxs import refractive_index_NBK7
from src.systems import GalileanTelescope

image = cv2.imread("assets/PIA01464.jpg")

system = GalileanTelescope(f1=100, f2=-20, color=True)
output = system.image_infinity(image)

print(system.focal_length())
print(system.magnification())
```

### Build systems from elements

```python
from src.elements import ThickLens, FreeSpace
from src.systems import OpticalSystem
from src.refractive_idxs import refractive_index_NBK7

system = OpticalSystem(color=False)
system.add_element(ThickLens(R1=308.2, R2=-308.2, d=5.1, n=refractive_index_NBK7(0.55)))
system.add_element(FreeSpace(25))
```

## Notes

- The code uses paraxial matrix optics, so it is best suited for first-order analysis and educational simulations.
- Color support is handled by tracing red, green, and blue channels separately with wavelength-dependent refractive indices.
- The notebooks and results folder are useful references for expected inputs and outputs, but they are not required to import or use the library code.
